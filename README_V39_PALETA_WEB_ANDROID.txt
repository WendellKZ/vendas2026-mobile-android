Passo 2:
1. Extraia o zip.
2. Abra a pasta no Android Studio.
3. Confira AppConfig.kt com a URL do Render.
4. Sync Project with Gradle Files.
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
