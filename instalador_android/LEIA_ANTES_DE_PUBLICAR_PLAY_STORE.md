# Antes de publicar na Play Store

Para Play Store, não envie o APK debug. Gere um Android App Bundle assinado:

```text
Build > Generate Signed Bundle / APK > Android App Bundle
```

Será necessário criar uma chave de assinatura. Guarde essa chave com muito cuidado, pois ela identifica o aplicativo nas próximas atualizações.

Para testes internos, o APK debug já atende.
